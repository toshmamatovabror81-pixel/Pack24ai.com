# Gofrokarton asoslari

## 1. Tuzilish
- Gofrokarton (corrugated fiberboard / гофрокартон) = gofrlangan o'rta qatlam (fluting, medium / флютинг) + 1–2 tekis layner (linerboard / лайнер); ikkalasi konteynerbord (containerboard / тарный картон), qalinlik >0.25 mm [wikipedia.org]
- Single face (2 qatlam) → single wall (3) → double wall (5: 3 layner + 2 fluting) → triple wall (7; ASTM D5168) [wikipedia.org] [iopp.org]
- Katta flyuta = shtabel mustahkamligi va amortizatsiya; kichik = teshilishga chidamlilik va bosma; double wall'da kichik flyuta tashqarida (B over C) [eng.uc.edu] [gwp.co.uk]

## 4. Grammaj va sarf
- Take-up α (коэффициент гофрирования) = fluting maydoni / karton maydoni (C: 1.43). Karton g/m² = tashqi liner + ichki liner + fluting×α + yelim: 175 + 175 + 140×1.43 (=200) + 2×5 = 560 g/m² [fefco.org]
- Kraxmal yelim (starch glue) har qatlam: A 4.5–5.0, B 5.5–6.0, C 5.0–5.5, E 6.0–6.5, F/G/N 9–11 g/m² [fefco.org]
- FEFCO 0201 misol: 575×385×225 mm, C, quti 650 g; blank 1.95×0.61 m, varaq 1.2935 m² (724 g); gofroagregat qirqimi 3 %; kirim 746 g → chiqindi 96 g = 12.9 % [fefco.org]
- Qog'oz tannarxning 60–80 %; 1 mln ft² = 60–70 t qog'oz; chiqindi 5–7 %; zaxira 5–6 hafta [eng.uc.edu]

## 7. BCT hisoblash (McKee / формула Мак-Ки)
- Soddalashtirilgan: BCT = 5.87 × ECT × √(Z × t) (lb; ECT lb/in; Z = 2(L+W) in; t qalinlik in); shart d ≥ Z/7 [gatech.edu]
- To'liq: BCT = 2.028 × ECT^0.746 × (√(DMD×DCD))^0.254 × Z^0.492 [gatech.edu]
- ECT (Maltenfort) = 0.7 × (2×SCT_liner + α×SCT_medium); 42-26C → 8.9 kN/m [ncsu.edu]
- Tipik ECT: 35-26C-35 → 7.6 kN/m (542 g/m², 4.14 mm); 42-26C-42 → 9.8; 26-23C-26 → 5.3; 42-26E-42 → 10.6 [ncsu.edu]
- Tuzatish: ECT = γ_ECT×ECT_avg (0.8 gacha), h_c = γ_h×h (bosma/shtamp zarari); P_calc ≤ BCT ≤ P_theor [up.poznan.pl]
- Talab P = Q×γ1×γ2×γ3×γ4 (1 kN ≈ 100 kg); umumiy γ 3.0–3.5 oqilona, 5.0 ortiqcha [up.poznan.pl]; amalda 3–7, dastur bilan 2:1, global 6–7 [pkgsolutions.co.uk]

## Tekshiruv (asosiy da'volar manbadan qayta o'qildi)

- ✅ **tasdiqlandi** — Bir qavatli gofrokarton grammaji = tashqi liner + ichki liner + fluting × take-up factor + yelim; C gofr misoli: 175 + 175 + 140×1.43 (=200) + 2×5 = 560 g/m²; C gofr take-up 1.43, yelim har qatlam A 4.5–5.0, B 5.5–6.0, C 5.0–5.5, E 6.0–6.5, F/G/N 9–11 g/m² (fefco.org)
  - Sabab: FEFCO "Corrugated board production" sahifasi (https://www.fefco.org/node/1588) da'voning barcha qismlarini tasdiqlaydi. Sahifada: (1) gofrokarton grammaji liner + liner + fluting × take-up factor + yelim yig'indisi sifatida hisoblanadi; (2) "a typical take-up factor for C-flute is 1.43" (jadvalda C: 1.40–1.45, A: 1.50–1.55, B: 1.30–1.35, E: 1.20–1.35, F/G/N: 1.15–1.25); (3) FEFCO 0201 C gofr misoli aynan shunday: Kraftliner 175 + Recycled Fluting "1,43 x 140 = 200" + Testliner 175 + Glue "2 x 5 = 10" = 560 g/m²; (4) yelim sarfi har bir yelim qatlamiga: A 4.5–5.0, B 5.5–6.0, C 5.0–5.5, E 6.0–6.5, F/G/N 9.0–11.0 g/m². Qo'shimcha: EPA sahifasi C gofr take-up ≈1.44 deb beradi, bu FEFCO diapazoniga mos.
- ✅ **tasdiqlandi** — Soddalashtirilgan McKee: BCT = 5.87 × ECT × √(Z × t) (BCT lb, ECT lb/in, Z = 2(L+W) in, t qalinlik in), faqat quti balandligi d ≥ Z/7 bo'lganda; to'liq shakl BCT = 2.028 × ECT^0.746 × (√(DMD×DCD))^0.254 × Z^0.492 (research.gatech.edu)
  - Sabab: Ikkala research.gatech.edu manbasi da'voni tasdiqlaydi. (1) "Effects of Moisture Content on Box Compression Strength" (research.gatech.edu/sites/default/files/2021-06/effects-of-moisture-content-on-box-compression-strength.pdf), (5)-tenglama: "BCT = 5.87 x ECT x √(Z x t)", "Z being the perimeter footprint (length + width) x 2 of the box, t the caliper", "The units in (5) for BCT, ECT, Z, and t are lbs., lbs./in, and inches respectively." (2) "Predicting Box Compression Strength" slaydlari (research.gatech.edu/sites/default/files/rbi/pdfs/Predicting%20Box%20Compression%20Strength_3.pdf): to'liq shakl "BCT = 2.028 ECT^0.746 (√(DMD·DCD))^0.254 Z^0.492" (McKee et al. 1963 ma'lumotlari bo'yicha konstantalar), soddalashtirilgan shakl 5.87 konstanta bilan "easy but not accurate" deb berilgan; 29-slaydda balandlik sharti: "d ≥ 2 x (L + W)/7 or d ≥ Z/7 Otherwise: BCT ≈ C'ECT x Z". Barcha raqamlar, birliklar va d ≥ Z/7 sharti da'vodagi bilan mos.
